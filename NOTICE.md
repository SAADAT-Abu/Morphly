# Notice on licensing

The MIT licence in `LICENSE` covers **Morphly's own source code**.

It does **not** cover the scientific illustrations Morphly displays. Morphly
does not bundle, host or redistribute any artwork — it reads an asset library
folder from your machine. Each illustration carries its own licence, set by
whoever created it:

| Library | Licences |
|---|---|
| [NIH BioArt Source](https://bioart.niaid.nih.gov) | Public Domain (some entries CC BY) |
| [Bioicons](https://bioicons.com) | Per icon: CC0 1.0, CC BY 3.0/4.0, CC BY-SA 3.0/4.0, MIT, BSD-3-Clause |

When you place an illustration in a figure, that illustration's licence applies
to your figure — not Morphly's. Most require only that you credit the artist,
which Morphly can write into your export automatically. A small number are
share-alike, which can require the resulting figure to be shared under the same
licence.

See **Help → Licensing** inside the app, or the Licensing section of the README.
